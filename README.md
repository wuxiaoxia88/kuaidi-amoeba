# 快递阿米巴模式

把稻盛和夫的阿米巴经营，改造成**通达系加盟快递网点 / 管理中心**能用的经营框架：怎么划小核算单元、分拣一票该定多少钱、内部怎么结算、单位时间附加值怎么算、哲学和激励怎么配套。

这不是咨询公司的课件。作者是一线网点的经营者，这个仓库是**边做边写**的：先把理论和方案摆出来，然后在自己的网点里试点，碰到问题解决问题，过程和数据（脱敏后）都记在 [`journal/`](journal/) 里。

> 状态：**立项阶段**（2026-10-27）。方案 v0.1 已成稿，尚未在网点试点。

## 为什么是快递网点

快递网点天生就有一半是「阿米巴」了：

- 承包区按票拿派费，外包客服按单收费，支线运输按车次或按票付钱，有的网点连财务都外包——**内部早就有价格，只是没人把它当成经营体系来设计**。
- 票是天然的计量单位。每一票从班车到车、卸车、分拣到派送，扫描记录全在系统里，算「每一道工序挣了多少钱」不缺数据。
- 压力是真的：派费在降、价格战在打、设备上了总部反手降派费。粗放的「老板一本账」已经撑不住，网点需要每个环节自己算账、自己想办法。

但快递网点也有阿米巴最怕的坑：工序串联、谁也离不开谁，内部定价一不公平就内耗；承包区一追利润就把件全扔驿站；罚款到底算谁的永远吵不清。这个项目就是要把这些坑一个个填上。

## 30 秒看懂核心算法

```bash
python3 tools/amoeba.py examples/demo-site.json            # 按现行内部价出核算表
python3 tools/amoeba.py examples/demo-site.json --suggest  # 按「各巴单位时间附加值相同」倒推内部价，再用外包价封顶保底
```

一条作业线（比如进港线）每票能分的钱是固定的：总部派费减去网点平台费。工具做的事是：

1. 先把场地、设备、系统这些公共费用按「谁用谁担」分到每个巴；
2. 再按稻盛的定价原则，让线上每个巴的**单位时间附加值大体相同**，倒推出每一票该给进港操作多少、班车多少、客服多少、派送多少；
3. 最后拿外包市场价做「社会常识」校验：内部价不能高过外包价太多，否则就该问一句「为什么不外包」。

示意数据跑出来的结论（详见 [05](docs/05-单位时间核算表.md)，进港各环节的量级参考了两个一线网点的进港成本单和一份总部全网进港成本对比，脱敏成区间）：进港操作自己干一票三分多，交给中心一票一毛，一个月差五万左右；按老规矩一票三分的进港班车，每小时只挣 8 块，司机时薪 25；出港线如果只看均衡，出港操作每票要给到 0.40 元，而一线行情是两毛到两毛五——这正是稻盛提醒的「简单工序拿高价」陷阱，必须用市场价约束。全网对标还说明了一件事：把每一项的最优拼起来，是一个不存在的网点——运营成本为零的网点，是让业务员兼职分件，钱进了派费。

## 配套工具

核算需要数据。作者另外开源了几个网点经营工具，可以作为阿米巴核算的数据底座：

- [盈亏透镜 profit-lens](https://github.com/wuxiaoxia88/profit-lens)：按客户算发件盈亏、辅助报价（业务巴的核算基础）
- [成本标尺 outbound-cost-studio](https://github.com/wuxiaoxia88/outbound-cost-studio)：出港账单按流向 × 重量段拆线上成本（业务巴报价先扣的那一格）
- [site-cash-recon](https://github.com/wuxiaoxia88/site-cash-recon)：网点现金对账与现金口径利润（会计七原则里的「现金本位」）
