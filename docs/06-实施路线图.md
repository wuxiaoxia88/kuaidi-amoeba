# 06 实施路线图

12 个月，五个阶段。每个阶段有验收标准，过不了就不进下一阶段。

## 阶段 0：诊断（第 1 个月）

| 要做的事 | 产出 |
|---|---|
| 画出本网点的价值链，确认每个环节的人、工时、费用 | 价值链图 + 人员工时表 |
| 从系统导出最近 3 个月每个环节的票数 | 票数台账 |
| 整理所有费用，按「谁受益」打标签 | 公共费用分摊表初稿 |
| 收集外包参考价（每个环节至少 2 家） | 外包参考价台账 |
| 用工具跑「老规矩」核算表 | 第一张核算表 |
| 找出 2–3 个最明显的不公平（谁在补贴谁） | 诊断报告 |

验收：老板和核心骨干看完第一张核算表，能说出「原来是这里在亏」。

## 阶段 1：统一思想（第 1–2 个月）

| 要做的事 | 产出 |
|---|---|
| 核心团队学习：阿米巴三个目的、定价原则、「作为人，何谓正确」 | 学习记录 |
| 共同写出网点自己的经营理念（不超过 10 条，用大白话） | 网点经营理念 |
| 确定巴的划分和巴长人选 | 组织划分表 |
| 讨论并通过：平台费、内部价格表、公共费用分摊规则、质量归责规则、调解规则 | 规则汇编 v1 |
| **明确承诺：前三个月不改任何人的收入** | 书面承诺 |

验收：每个巴长能用自己的话讲清楚「我这个巴怎么挣钱、怎么花钱」。

## 阶段 2：单巴试点（第 2–4 个月）

选一个巴先跑。建议选**进港操作巴**：工序清楚、数据全在系统里、人员集中、巴长好找。

| 要做的事 | 产出 |
|---|---|
| 每天出进港操作巴核算表 | 日核算表 |
| 每周巴长例会 | 例会记录 |
| 第一个月做「预定」，月底比实绩 | 预定 vs 实绩 |
| 记录所有争议、调整 | journal 日志 |

验收：连续 4 周按日出表；巴长能讲出至少 3 个改善点，且至少 1 个已经在核算表上看到效果。

## 阶段 3：进港线全线（第 4–6 个月）

| 要做的事 | 产出 |
|---|---|
| 进港运输、客服、派送加入，按内部价结算 | 进港线全线核算 |
| 质量归责进核算表 | 质量扣款明细 |
| 调解机制启动 | 争议单记录 |
| 第一次价格调整会（按实际数据重跑均衡） | 内部价格表 v2 |

验收：进港线 4 个巴连续 2 个月出表；争议都有调解结论；没有核心人员因为核算离职。

## 阶段 4：出港线 + 激励（第 6–12 个月）

| 要做的事 | 产出 |
|---|---|
| 出港线加入：业务、上门揽件、出港操作、支线运输、客服 | 全网点核算 |
| 月度经营会制度化 | 经营会纪要 |
| 设计激励方案（见下） | 激励方案 v1 |
| 激励试运行一个季度 | 季度复盘 |
| 人才裂变：选出 1–2 个潜在新巴长 | 后备巴长名单 |

### 激励方案的设计原则

结合京瓷「不直接挂钱」和永辉「超额分享」：

1. **基本收入不动**：计件、底薪照旧。
2. **门槛在前**：巴的月度附加值超过「预定」才进入分享。
3. **超额分享、平滑发放**：超额部分按比例（示意：网点与巴三七开）进巴的奖金池；按季度发，设上限和保底，避免大起大落。
4. **荣誉优先**：月度经营会上表扬改善最大的巴，而不是附加值最高的巴。
5. **长期挂钩**：巴长晋升、带新巴（裂变）、成为合伙人，看的是长期表现。
6. **红线 + 底线一起设**（南京邮政快包的做法）：附加值有盈亏平衡红线，票量也有底线，防止为了好看的单价把客户和量砍掉。
7. **可选：巴长保证金对赌**（山东邮政合伙人制的做法）：巴长每年交一笔小额保证金，达目标全退，达挑战目标加奖，不达标不退。只对自愿报名的巴长，且要先过合规审查。
8. **业务员的价差返还**（义乌邮政的做法）：报价高于网点基准价的部分，按比例返给业务巴，鼓励守价格。

## 阶段 5：持续运营（第 12 个月以后）

- 每半年更新外包参考价，重跑均衡价。
- 每年评估一次巴的划分：该合并的合并，该拆的拆。
- 每年更新一次网点经营理念。
