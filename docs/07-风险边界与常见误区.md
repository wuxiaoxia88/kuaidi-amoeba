# 07 风险、边界与常见误区

## 1. 合规边界

> 以下是经营上的提醒，不是法律意见。涉及用工、合同、税务的具体安排，请咨询当地律师和税务师。

| 风险 | 说明 | 做法 |
|---|---|---|
| 劳动关系 | 把员工「包装」成承包人来规避社保、劳动合同，是违法风险 | 内部核算不改变劳动关系；员工还是员工，核算只是经营工具 |
| 承包合同 | 承包区如果是独立经营的个体，内部价就是真实交易价，要有合同 | 合同写清计价、质量责任、公共资源使用费 |
| 税务 | 内部巴之间的结算是管理核算，不是真实交易，不需要开票；和外部主体的结算才是真实交易 | 两套账分清：管理核算表 ≠ 财务报表 |
| 总部政策 | 派费、罚款、考核由总部定，网点不能自己改 | 总部政策是外部价格，只在网点内部传导 |
| 数据安全 | 核算表里有收件人、客户信息 | 核算表只用票数和金额，不带个人信息；公开前脱敏 |

## 2. 经营风险

| 风险 | 表现 | 预防 |
|---|---|---|
| 本位主义 | 各巴只顾自己的数字，推卸责任 | 经营哲学；质量归责；整体目标优先 |
| 数据造假 | 巴长为了好看改数字（京瓷也发生过） | 以系统扫描为准；双重确认；玻璃般透明 |
| 定价内耗 | 天天吵价格，没人去改善 | 价格半年一调；调解有成本；表扬改善而不是表扬数字 |
| 过度拆分 | 核算比干活还累 | 先 8 个巴起步；核算表一页纸 |
| 只拆不合 | 规模变了组织不变 | 每年评估一次划分 |
| 承包区甩件 | 为了省钱全扔驿站 | 投诉、虚假签收罚款实时进派送巴的账 |
| 好人吃亏 | 帮别人的巴，自己的工时被占 | 支援时间精确划转（0.5 小时） |

## 3. 常见误区

综合《阿米巴经营》、上海国家会计学院案例课件和《利润裂变》：

1. **把阿米巴当成算奖金的工具**。阿米巴是经营体系，奖金只是很小的一部分。一上来就挂钱，所有人都会去吵价格。
2. **认为阿米巴是一个项目**。项目有结束的一天，阿米巴没有。
3. **全员参与 = 全面授权**。巴长有经营权，但平台费、质量规则、调解规则是统一的。
4. **全部信息公开**。经营数字公开，客户信息、个人工资明细不公开。
5. **导入就能立刻高收益**。前三个月往往是「发现问题」，数字可能更难看。
6. **职能部门也要盈利**。见 [03](03-网点组织划分.md) 第 2 节。
7. **越细越好**。见 [01](01-理论精要.md) 第 2 节。
8. **只学术，不学道**。新一佳的教训。

## 4. 这套方案不能解决的问题

- **总部派费太低**：阿米巴能让网点看清「派费只够保本」，但不能让派费变高。它能做的是逼出效率改善，或者为和总部谈判提供数据。
- **货量太小**：日票量几百的网点，划巴没有意义，老板一本账就够。
- **老板不愿意放权、不愿意公开数字**：阿米巴的第一个前提是高层支持。老板不改，什么都不会改。
