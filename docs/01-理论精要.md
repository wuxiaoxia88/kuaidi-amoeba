# 01 理论精要

这一篇把阿米巴的核心概念压缩成网点经营者需要知道的部分。每一节最后有「放到快递网点」的对照。

## 1. 阿米巴是什么

阿米巴（Amoeba，变形虫）经营是稻盛和夫在京瓷创立的经营方式：把公司划分成很多个**能独立核算的小集体**，每个小集体有一个负责人（巴长），像一个小公司一样自己定计划、自己算账、自己改善。小集体之间按内部价格买卖产品和服务。

稻盛给它定了三个目的：

1. **确立与市场直接挂钩的分部门核算制度**。市场价格一变，每个部门马上感觉到。要的不是月底的财务报表，是「现在的数字」。原则是「销售最大化、费用最小化」。
2. **培养具有经营者意识的人才**。公司变大以后，一个老板管不过来；划小以后，每个巴长都在学当老板。
3. **实现全员参与的经营**。经营理念共有、信息共有，员工在工作中感到价值和成就感，化解劳资对立。

> 放到快递网点：老板一个人盯全网点的账 → 分拣组长盯分拣的账、承包区负责人盯承包区的账、客服组长盯客服的账；每天下班前知道今天这条线挣了多少。

## 2. 怎么划分：三个条件

稻盛提出，一个单元能不能成为阿米巴，要同时满足：

1. **有明确的收入，且能算出为了这份收入花了多少费用**——能独立核算；
2. **是一个能独立完成业务的单位**——巴长有钻研创新的空间，能体会到经营的乐趣；
3. **划分后不妨碍公司整体目标和方针的落实**。

还有两个补充：

- **组织并非越小越好**。分得太细，核算成本比收益还大；分得太粗，问题被平均掉。稻盛说「阿米巴组织如何切分，这是阿米巴经营的开始，也是阿米巴经营的终结」。京瓷自己也是 30 多年后才把物流单独拆成一个事业部。
- **没有合格的巴长，就不划**。《利润裂变》把这一点列为划分的第一个关键点：先有人，再有巴。

> 放到快递网点：一个承包区有收入（派费）、有费用（车辆、驿站代派），负责人能决定路线和投递方式——满足三个条件；一个只有 2 个人的卸车小组，如果和分拣在同一个班次、同一个场地、没法单独计量，就不该拆出来。

## 3. 内部定价：阿米巴的心脏

### 3.1 稻盛的定价原则

- **从最终卖价向前倒推**，决定每道工序的价格。
- 倒推的标准：**各道工序都能获得大体相同的「单位时间附加值」**。
- 但必须用**劳动价值的社会常识**校正：假设某道工序技术含量很低，按均衡原则它也能拿到很高的单位时间附加值，但如果外包这道工序很便宜，那内部价就太高了——它不用努力就能赚很多，而难的工序再努力也亏。
- 定价的人必须熟悉行情：这种活外面临时工多少钱一小时、外包要付多少钱。
- 市场价变了（比如降价 10%），不能一刀切地每道工序都降 10%，要由上一级领导人听取各方意见，**像公正的法官一样**重新判断。

### 3.2 定价方法（《利润裂变》的归纳）

| 方法 | 做法 | 适用 |
|---|---|---|
| 成本基础 | 按本工序成本（变动成本、完全成本、标准成本）加合理利润 | 没有外部市场、只能内部做的服务 |
| 市价基础 | 直接用外部市价，或「市场倒推」：从最终售价倒推各环节 | 有外包市场可比的服务 |
| 协商定价 | 双方在一定区间内谈 | 双方都有替代选择时 |

四项原则：**自愿接受、公平合理、服务业务发展**（不能为了核算阻碍业务）、**激励与约束**。

### 3.3 内部市场的四种类型

按巴之间合作、竞争的程度，内部市场分为简单型、合作主导型、竞争主导型、复合型。复合型最常见：内部服务也可以从外部市场买，内部巴必须同时面对内外两个市场的竞争。

> 放到快递网点：网点就是典型的**复合型内部市场**——分拣可以自己做也可以外包，客服可以自建也可以外包，支线运输可以自有车也可以找车队。所以内部价必须对标外包价。

### 3.4 定价的裁判

价格吵起来时，稻盛的办法是上一级领导人当裁判，用经营哲学而不是谁嗓门大来判断。《利润裂变》把它制度化：成立**调解委员会**（老板、相关巴长、财务、运营），定价调解参考成本、利润和市场价，规则修改要 2/3 通过，申请调解的一方要承担调解成本，败诉方付钱——防止什么事都往上推。

## 4. 单位时间核算

这是阿米巴的「仪表盘」。

```
总出货（内部 + 外部收入）
− 内部采购（从其他巴买的）
= 本巴的销售额
− 费用（材料、设备折旧、电费、场地分摊……，**不含本巴人员的工资**）
= 附加值（结算收益）
÷ 总时间（正常工时 + 加班 + 支援调入 − 支援调出 + 分摊的公共时间）
= 单位时间附加值（元/小时）
```

几个要点：

- **人工费不扣**。附加值减掉的是「除了人以外的一切」，剩下的就是这个巴靠人创造的价值，除以小时，就能直接和时薪比：每小时创造的附加值有没有超过每小时的人工成本。稻盛举例：每小时劳务费 3600 日元，就是「一秒一日元」，现场每个人都要做出超过这个数的附加价值。
- **用金额，不用数量**。所有票据写金额，而不是只写「做了几个」。网点里就是：不说「今天分了 2 万票」，说「今天进港操作挣了 800 块」。
- **时间精确到半小时**。闲的巴派人去支援忙的巴，时间从一边划到另一边。
- **月度预定和实绩**。每月初做「预定」（计划），每天跟踪，月底对比分析，下个月的预定根据分析修正——就是 PDCA。

> 放到快递网点：进港班车每小时只创造 8 元附加值，司机时薪 25 元——车每多跑一小时，网点贴十七块。这个数字比「班车一票三分钱」更能让车队长坐不住。

## 5. 京瓷会计七原则

支撑核算的七条会计原则：

| 原则 | 意思 | 网点对照 |
|---|---|---|
| 现金本位 | 以现金流动为基础判断经营 | 派费到账、罚款扣款、驿站付款，按现金口径记 |
| 一一对应 | 每一笔钱的流动都要有对应的票据，物和钱一一对应 | 每张内部结算单对应扫描记录 |
| 筋肉坚实 | 不留赘肉：不囤闲置资产、不留多余库存和设备 | 闲置的车、长期不用的格口、多余的巴枪 |
| 完美主义 | 数字不容许差错 | 核算表不能「差不多」 |
| 双重确认 | 关键环节两个人确认 | 结算单巴长和接收方都签 |
| 提高核算效益 | 一切为了提高附加值 | 每个改善都要落到核算表上 |
| 玻璃般透明 | 经营公开，让员工看到真实的数字 | 核算表全员公开 |

## 6. 经营哲学

稻盛强调，没有哲学的阿米巴会变成小团体互相厮杀：每个巴都想把自己的数字做漂亮，压低进价、抬高卖价、隐瞒问题、推卸责任。

他的回答是一句话：**「作为人，何谓正确」**——不撒谎、不骗人、要正直；利他；在维护本巴利益的同时，追求整体利益最大化。

京瓷的薪酬也体现了这一点：**单位时间附加值高，不直接给高额奖金**；成绩会长期反映在待遇里，但短期奖励是「被伙伴们赞赏的荣誉」。稻盛反对欧美式的赤裸裸绩效主义：业绩好时拿高报酬会习以为常，业绩差时报酬一降就生怨恨。

## 7. 中国化：合伙人制

中国企业很少照搬京瓷的「不直接挂钱」。《利润裂变》的观点是：合伙人制让阿米巴「如虎添翼」，但要避开几个老坑：

- **利润留成制**：按销售额提成，经济下行期业务单元大赚、公司整体亏，信息不对称时代理人多拿多吃。
- **承包制**：交够承包费剩下归自己，短期行为严重，责权利界定不完整。
- **明晰产权（员工持股）**：要么是空头支票，要么公司利益受损。

阿米巴合伙人制的思路是「以战功论英雄」：用经营会计让核算透明公平，用经营哲学保证互信，用选拔、考核、分配三套规则管住人。

> 放到快递网点：承包区本质上就是「承包制」，所以它的老毛病（只顾自己、甩锅给网点）在网点里天天发生。阿米巴要做的不是取消承包，而是给承包加上**质量进账、公共费用分摊、透明核算和哲学约束**。
