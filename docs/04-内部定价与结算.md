# 04 内部定价与结算

这是整个方案的核心。所有数字都是**示意数据**，方法可以照搬，数字必须换成自己网点的。

## 1. 每一票的钱从哪来、到哪去

### 进港线

```
总部结算给网点的到手派费（示意：0.90 元/票；★ 一线一票八毛四到九毛七）
  − 网点平台费 0.06（管理团队、财务、行政、房租水电、老板投资回报）
  − 中心赋能装车 0.01（付给中心，外部价）
  = 可分配单价 0.83 元/票
     ├─ 进港操作巴（卸车、拆包、分拣、扫描）
     ├─ 进港运输巴（中心到网点的支线班车）
     ├─ 客服巴（进港）
     └─ 派送巴（承包区、业务员；直送线路另算） ← 剩余归它（利润巴）
```

### 出港线

```
客户平均运费 − 面单费 − 中转费（给总部，外部价）= 留在网点的部分（示意：0.90 元/票）
  − 网点平台费 0.06
  = 可分配单价 0.84 元/票
     ├─ 上门揽件巴（揽收扫描，按票计提成）
     ├─ 出港操作巴
     ├─ 支线运输巴
     ├─ 客服巴（出港）
     └─ 业务巴 ← 剩余归它（利润巴）
```

**「平台费」为什么要先扣**：网点老板投了场地、设备的钱，承担了总部罚款的连带风险，还要养财务和管理。这部分不能靠「最后剩多少算多少」，要像韩都衣舍的平台一样明确收费。平台费要公开、要说明构成、一年只调一次。

**剩余为什么归利润巴**：利润巴直接对市场。业务巴（业务员开发和维护发件客户）把价格报高了、客户结构做好了，钱多出来是它的本事；报低了，亏的也是它。派送巴同理：总部派费变了，首先体现在派送巴的收入上。这符合稻盛「与市场直接挂钩」的要求，让离市场最近的人最先感到压力。

## 2. 定价三步法

### 第一步：成本摸底

每个服务巴，先算清楚现在的成本，**分两部分**：

- 非人工费用（设备月供折日、电费、耗材、车辆油电、场地分摊、系统）
- 人工（人数 × 工时 × 时薪）

示意：一个没有分拣设备的网点，进港操作巴 10 人，早班干 3.5 小时 = 35 工时，时薪约 22 元；电费耗材 60 元，系统巴枪分摊约 20 元。日进港 25000 票。

```
非人工费用 ≈ 60 + 20 = 80 元
人工       ≈ 35 × 22 = 770 元
全成本     ≈ 850 元 ÷ 25000 票 ≈ 0.034 元/票
```

这个量级和一线对得上：没有设备、自己人干的网点，进港操作一票三到五分；交给中心代操作，一票一毛。见第 3 节。

### 第二步：单位时间均衡

按稻盛原则，让同一条线上每个巴的单位时间附加值大体相同。数学上很简单：

```
v   = （票数 × 可分配单价 − 各巴非人工费用之和）÷ 各巴工时之和
p_i = （巴 i 的非人工费用 + v × 巴 i 的工时）÷ 票数
```

`v` 就是整条线「每小时能创造的附加值」，`p_i` 是巴 i 每票应得的内部价。用 [`tools/amoeba.py --suggest`](../tools/amoeba.py) 直接算。

示意结果（进港线）：

| 巴 | 均衡内部价/票 |
|---|---|
| 进港操作巴 | 0.033 |
| 进港运输巴 | 0.043 |
| 客服巴（进港） | 0.019 |
| 派送巴 | 0.736 |

整条线 v = 21.2 元/时。注意客服：按均衡只值 1 分 9，低于外包进港的行情 2 分 5，第三步会把它保底到 2 分 5，派送巴相应变成 0.729。

### 第三步：用外包价校正（社会常识）

拿每个服务巴的**外包市场参考价**做上下限：

- 均衡价**高于**外包上限 → 封顶到上限。这道工序如果内部比外包贵，要么提效，要么认真考虑外包。
- 均衡价**低于**外包下限 → 保底到下限。这个巴在补贴别人，长期下去没人愿意干。
- 封顶保底后多出来或少掉的钱，全部归利润巴。

出港线就是一个典型：纯均衡时 v = 66.8 元/时，出港操作巴每票要给 0.293 元，上门揽件要给 0.25 元，都是行情的两倍多。原因是业务巴的单位时间附加值太高（客户运费里的利润主要是业务员谈客户谈出来的），均衡会把业务的钱「平均」给操作和揽件。这就是稻盛提醒的：**简单工序不能靠定价躺赚**。封顶后，上门揽件 0.12、出港操作 0.12、支线 0.09、客服 0.02，业务巴拿剩下的 0.490。

> 外包参考价从哪来：问两到三家外包公司报价；看同城其他网点的承包、外包价格；用自己过去外包的合同价。每半年更新一次，记录在 [`templates/外包参考价台账.csv`](../templates/外包参考价台账.csv)。

| 环节 | 计价单位 | 示意内部价 | 参考区间 | 定价方法 | 备注 |

| 客服（出港） | 元/票（出港票数） | 0.02 | ★ 0.015–0.02 | 市价封顶 | 出港工单少、处理简单 |

### 进港操作：自己干还是交给中心

两个一线网点的进港成本单，正好是两种做法：

| | 自己干（没有设备） | 交给中心代操作 |
|---|---|---|
| 单票操作成本 | 一票三分左右（同组均值四到六分） | 一票一毛，中心直接代扣 |
| 人 | 二十来个人干早班，卸车、拆包、分拣到承包区和业务员 | 网点只留两三个人 |
| 网点要管的事 | 招人、排班、错分、早班出勤 | 几乎不用管，但时效和错分要靠中心 |

示意网点算下来，自己干的均衡价是 3 分 3，外包价是 1 毛，**一票差 6 分 7，一天两万五千票就是一千六百多块，一个月五万左右**。这就是第 9 节说的「外包价是内部巴的挑战目标」：内部巴做到一票三分多，外包价就是它的护城河；哪天内部做到一毛以上，就该问「为什么不交给中心」。

但账不能只算这一笔。交给中心的网点往往是场地小、离中心近、件量不大、招不到早班工人——这时候一毛买的是「不用管」。阿米巴要算的是**单位时间**：网点老板和管理团队省下来的时间，去做业务、做直送，挣不挣得回这六分七。

### 投递：承包区、业务员、直送

投递是进港线最大的一块钱，两个一线网点的结构完全不同：

- 一个以承包区为主，承包区一票五毛七到八毛八，业务员加权五毛三左右；
- 一个全是直营业务员加直送：计件业务员一票八毛到九毛，固定工资的业务员每月八千到八千五；三分之一的件走直送。

**直送**是把驿站和柜子串成线路，网点派车把件直接送到店，入库费由网点直接付给门店，不经过承包区和业务员。一线口径：按票付短驳的三轮车线路一票两毛到两毛五，加入库费四毛到四毛五，**一票五毛七左右，比计件业务员便宜两毛多**。但按月付工资的货车线路，件少的时候一票短驳能到七毛五——所以直送线路也要按单位时间核算，件量撑不起来的线路不如交回业务员。

**固定工资和计件**：固定工资的业务员件量一掉，单票成本马上涨（一线成本单里的差异原因原话是「固定工资人员件量下降」）。阿米巴的做法是两种都换算成「单票成本」和「单位时间附加值」放在同一张表里比，而不是只看工资总额。

**入库费谁付**：同一个网点里，有的入库费网点直接付，有的由业务员自己付。一线口径：驿站一票四毛到五毛，柜子两毛到四毛，地区差异大。内部价表里必须写清楚派送价「含不含入库费」，否则承包区、业务员之间根本没法比。

### 上门揽件：按货品分档计票

快递行业给揽件端的钱，本来就是**按票计提成**，一般一票一毛左右：

- 盒子多、要上楼、要打包、件型杂的客户，给到一毛二；
- 衣服这类好收的（软包、件型统一、批量拿），给到八分，甚至六分。

所以上门揽件巴的内部价不是一个数，而是**按客户分档**。档位跟着客户走，由业务巴在报价时就定好——业务员报给客户的价格里，要先扣掉这一档的揽件提成，剩下的才是自己的。

### 客服：进港出港分开计价

**一线经营口径**（作者网点和同行的做法）：

- 网点自有客服，把工资、社保、管理成本摊到每一票，**差不多 2 分钱一票**。
- 外包客服一般也以 2 分钱为基准，但不少地方**进港出港分开报价**：出港低一些，1 分 5、1 分 8，甚至更低；进港高一些，2 分 5 到 3 分。

为什么进港贵：进港产生的工单比出港多（查件、催件、投诉、拦截、改址、理赔大部分在进港），客服的售后时间也主要花在进港上。出港件量增加带来的人工处理成本，大约只有进港的一半。举个例子：一个网点两个客服处理日进港 2 万票，进港涨到 3 万票，两个人就处理不过来了；但出港从 2 万涨到 3 万，两个人还应付得了。

两个一线网点的成本单也印证了这个口径：一个网点自有进港客服摊下来一票 2 分 4；另一个是两名现场客服加外包，外包合同写的就是「进港 0.03，出港 0.02」，进港摊下来一票 3 分 6。

所以内部价也要进出港分开，否则出港线在替进港线付客服的钱。示意网点按老规矩一律 2 分，结果就是：进港客服给低了（低于外包行情），出港客服给高了（高于外包行情）。

### 客服：自有还是外包

| | 自有客服 | 外包客服 |
|---|---|---|
| 成本 | 工资、社保、管理，约 2 分/票；人员流动带来招聘、培训、管理成本 | 按票付费，网点不承担招聘、培训和管理 |
| 和快递员衔接 | 可以当面沟通，执行力强 | 远程工作和沟通，衔接不如本地顺畅 |
| 人才 | 一个熟练客服至少要 3–5 年才能养成，走一个损失很大 | 不用自己养，但也养不出自己的人 |

客服的工作分两类：

1. **重复性的**：常规查询、拦截、退改，大量是复制粘贴式的机械操作。这类工作最适合交给系统和 AI 工具做，也是外包能压低价格的原因。
2. **没有标准的**：要和投诉人打电话、线下沟通、协调快递员。这类工作靠经验，是熟练客服值钱的地方，也是自有客服的优势。

阿米巴的视角：把客服巴的工时分成这两类记录。重复性工时越少、非标工单处理得越好，客服巴的单位时间附加值越高——这比单纯比「每人每天处理多少单」更公平。

### 可选：责任工单内部计价

外部价格按票收，但网点内部可以再加一层：**谁的问题谁付钱**。派送巴扔驿站、虚假签收引发的投诉，如果全按票摊，客服巴等于白干、派送巴也没压力。

| 项目 | 示意价 | 谁付 |
|---|---|---|
| 投诉处理 | 3 元/单 | 责任巴（按责任判定） |
| 理赔处理 | 5 元/单 | 责任巴 |

这部分只在网点内部核算里用，不改变和外包客服的合同价。

## 4. 公共费用怎么分

四项原则（《利润裂变》）：直接受益、公平、一致认同、核算简易。

| 费用 | 分摊依据 | 示意 |
|---|---|---|
| 场地租金 | 实际占用面积（不含公共通道） | 月租 ÷ 可用面积 = 每平方米单价；分拣区 600 平、派送装车区 330 平 |
| 分拣设备 | 谁用归谁 | 有交叉带的网点，设备月供全部归进港操作巴 |
| 称重扫描设备 | 谁用归谁 | 归出港操作巴 |
| 巴枪、系统账号 | 账号数 | 每个账号每月固定价 |
| 水电 | 有电表的按表，没有的按面积 | |
| 网点平台费 | 已经在每票里先扣，不再二次分摊 | |
| 老板、财务、人事 | 不分摊，包含在平台费里 | 职能部门不做盈利巴 |

**设备闲置期不分摊**。如果一台设备某个月没人用，它的折旧不能硬摊给某个巴——这是平台的投资风险，由平台费承担。

## 5. 质量进账：罚款归谁

总部的罚款（投诉、虚假签收、延误、破损、遗失）是网点的外部成本。阿米巴的做法是：**按责任实时进入责任巴的核算表**，而不是月底一刀切。

| 问题 | 责任判定依据 | 进谁的账 |
|---|---|---|
| 虚假签收、未电联放驿站被投诉 | 签收记录 + 投诉内容 | 派送巴 |
| 分错格口导致延误 | 分拣扫描记录 | 进港操作巴（交给中心代操作的，按合同找中心） |
| 班车晚到导致派送延误 | 到车扫描时间 | 进港运输巴 |
| 出港漏扫、错发 | 出港扫描记录 | 出港操作巴 |
| 客服超时未回复被升级 | 工单时间戳 | 客服巴 |
| 原因不明 | 调解委员会判定；判不了的进平台费 | — |

正向的也要进账：总部的服务质量奖励，按贡献分给相关的巴。

## 6. 价格调整：总部降派费怎么办

这是网点最常遇到的场景。总部派费从 0.90 降到 0.75，这 0.15 谁来扛？

**错误做法**：一刀切，每个巴都降 15%；或者全部压给承包区。

**阿米巴做法**：

1. 外部价格变化，先体现在**利润巴**（派送巴）的收入上——它离市场最近。
2. 立刻用新的可分配单价重新跑一遍均衡（第二步）和市价校正（第三步）。
3. 召开价格调整会，听取各巴意见：派送巴能不能通过提高每小时派送量消化？直送能不能多做几条线？进港操作上了设备以后效率提升了多少？
4. 如果降派费是因为网点上了设备（总部认为网点成本降了），那么**设备带来的效率收益应该先用来覆盖降价**，而不是让快递员额外摊设备月供。设备月供本来就在进港操作巴的费用里。
5. 调整结果写进价格变更记录，公示一周后生效。

## 7. 结算流程

阿米巴的内部结算大多是**核算上的结算**，不是真的转账。只有和外部主体（外包公司、承包区如果是独立个体户）才发生真实付款。

```
每天
  系统导出各环节扫描票数 → 生成每个巴的「内部结算单」（票数 × 内部价）
  → 巴长确认（双重确认）→ 进入当日核算表

每周
  巴长例会：看本周单位时间附加值趋势、质量扣款明细

每月
  月初：各巴做「预定」（计划票数、费用、工时、单位时间附加值）
  月中：每天对比进度
  月底：预定与实绩对比分析 → 月度经营会 → 定下个月预定
  真实付款：外部承包区、外包服务按合同结算付款
```

数据来源一律以**系统扫描记录**为准（一一对应原则），手工数只作补充，要注明。

## 8. 吵架了怎么办：调解机制

| 项目 | 规则 |
|---|---|
| 申请条件 | 两个巴长对内部价、责任归属谈不拢，可以申请调解 |
| 调解委员会 | 网点负责人、相关巴长、财务、运营 |
| 依据 | 成本、利润、外包市场价、系统记录 |
| 调解成本 | 申请方先垫付（示意：50 元/次），判谁的责任谁出 |
| 规则修改 | 巴长可以提案，委员会 2/3 同意后生效 |
| 记录 | 每次调解写进 [`templates/结算争议单.csv`](../templates/结算争议单.csv)，公开 |

调解的根本依据是经营哲学：「作为人，何谓正确」，以及「整体利益优先」。

## 9. 外包与内部巴：怎么选

快递网点已经有大量外包（客服、运输、财务），阿米巴不是要把外包都收回来，而是让「自己做还是外包」变成一道算术题：

- 内部巴的全成本（非人工费用 + 人工）÷ 票数 **>** 外包价 → 先给内部巴 3 个月改善期；改善不了，就外包。
- 内部巴的全成本 **<** 外包价 → 留在内部；外包价就是它的「挑战目标」。
- 一线例子：进港操作自己干一票三分多，交给中心一票一毛（见第 3 节）。
- 外包以后，外包商就是一个**外部巴**：同样进入核算表，同样承担质量责任（写进合同）。

这就是复合型内部市场：内部巴和外部服务商同时竞争，价格始终接近市场。
