# 00 立项书

版本 v0.1 · 2026-10-27

## 1. 背景

### 1.1 行业压力

- **派费下行**：多篇行业报道提到，网点派件费从高峰期一票 1.5 元以上，降到一块钱上下；驿站代派费从一票一块多降到三到五毛。网点上了自动分拣，总部随后下调派费，网点只能把降幅继续往承包区和快递员身上传。
- **价格战与反内卷并存**：2026 年 9 月起，多家快递公司在部分省份上调电商件服务费一票一到一毛五，但涨的钱要经过总部、中转、网点多层分配，到末端还剩多少说不清。
- **外包已经很普遍**：外包客服按通话时长或按单收费，外包运输按车次或按票，承包区按票结算派费，有的网点财务也外包。网点内部早就是一个个「按票买卖」的关系，只是没有统一设计。

### 1.2 网点内部的老问题

| 现象 | 根子 |
|---|---|
| 老板一个人一本账，月底才知道赚没赚 | 没有「现在的数字」，只有过去的数字 |
| 分拣说派送装车慢，派送说分拣分错格口 | 工序之间没有价格，责任说不清 |
| 承包区把件全放驿站，投诉罚款网点背 | 派费是固定的，服务质量不进账 |
| 上了设备，人没少，钱先没了 | 设备投入没有算到具体的工序里，不知道回本靠谁 |
| 好的快递员留不住，差的赶不走 | 只有计件工资，没有经营者的成长路径 |

### 1.3 为什么是阿米巴

阿米巴经营的三件事，正好对上这些问题：

1. **与市场挂钩的分部门核算**：每一道工序都有价格、有收入、有费用，每天知道自己赚没赚。
2. **培养有经营意识的人才**：分拣组长、承包区负责人都是「巴长」，算自己的账，想自己的办法。
3. **全员参与经营**：数字公开，大家朝一个目标使劲，而不是老板一个人扛。

## 2. 目标

| 时间 | 目标 | 验收标准 |
|---|---|---|
| 第 1 个月 | 方案定稿 | 组织划分、内部价格表、核算表模板、结算流程四件套经过网点核心团队讨论通过 |
| 第 3 个月 | 一个试点巴跑通 | 试点巴连续 4 周按日出核算表，巴长能讲清自己的单位时间附加值和改善点 |
| 第 6 个月 | 进港线全线运行 | 分拣、接驳、客服、派送四个巴按内部价结算；结算争议有记录、有调解结论 |
| 第 12 个月 | 全网点运行 + 激励挂钩 | 出港线加入；月度经营会制度化；激励方案运行满一个季度，核心人员流失率不升 |

经营结果目标（试点后按实际数据再定）：单票综合成本下降、投诉和罚款下降、核心岗位留存提升。这里先不写具体数字，等诊断完再填，避免拍脑袋。

## 3. 原则

1. **先哲学，后核算**。新一佳的失败和很多中国企业的教训都是「只有术、没有道」。阿米巴的判断标准是「作为人，何谓正确」，内部定价要公平，数字要诚实。
2. **先看数，后分钱**。前三个月只出核算表、不改收入，让大家先习惯看账。直接把核算结果和奖金绑在一起，是阿米巴落地失败最常见的原因。
3. **价格要有社会常识**。内部价参照外包市场价，不能让简单工序靠定价躺赚，也不能让难的工序怎么干都亏。
4. **职能部门不做盈利巴**。财务、人事、数据这些是规则的制定者，不能既当裁判又当运动员。
5. **能简单就不复杂**。核算科目越少越好，分摊规则一张纸能讲清。网点没有专职经营管理部，规则复杂了就没人维护。
6. **合规第一**。阿米巴的内部结算是「经营核算」，不改变劳动关系、不改变和总部的合同关系，不碰税务红线（见 [07](07-风险边界与常见误区.md)）。

## 4. 范围与边界

**在范围内**：网点内部（含承包区、驿站合作）的组织划分、内部定价、结算、核算表、经营会议、激励与人才培养。

**不在范围内**：总部对网点的结算政策（面单费、中转费、派费、考核罚款）——这些是网点的「外部市场价格」，阿米巴只能接受并在内部传导，不能改。

## 5. 方法

- **理论**：稻盛和夫《阿米巴经营》为主干，《利润裂变：新阿米巴×合伙人制×数字运营》补充内部交易定价、公共费用分摊、调解机制和合伙人制。
- **案例**：国内外实践，按证据等级区分「有一手资料」和「只有二手说法」（见 [02](02-案例研究.md)）。
- **实践**：在作者经营的网点试点，过程写进 [`journal/`](../journal/)。
- **工具**：核算小工具 + 作者已开源的盈亏、成本、现金对账工具做数据底座。
