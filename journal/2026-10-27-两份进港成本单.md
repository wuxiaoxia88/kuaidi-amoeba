# 2026-10-27 两份进港成本单：把假设换成一线口径

## 拿到了什么

两个一线网点向总部填报的月度进港成本单（已归档），按总部口径拆成装车、运输、操作、管理、固定、投递六类，每一项都折成单票成本，还附了同中心、同区域网点的「同组均值」。

两个网点的打法几乎相反，下面叫 A、B。以下只写区间和比例，不写网点名、地区、人名和门店名。

| | A | B |
|---|---|---|
| 日均进港签收 | 约 5 万 | 约 1.7 万 |
| 离中心 | 五十多公里 | 三十公里以内 |
| 分拣设备 | 无 | 有（中心代操作） |
| 投递 | 承包区为主，业务员为辅 | 全部直营业务员，三分之一走直送 |
| 到手派费 | 八毛四左右 | 九毛七左右 |
| 单票进港总成本 | 七毛左右 | 九毛四左右 |
| 一票剩多少 | 一毛三左右 | 三分左右 |

## 新看到的东西

1. **自己干一票三分，交给中心一票一毛。** 示意网点一天两万五千票，差一千六百多块，一个月五万左右。外包价不是内部价，是内部巴的挑战目标。
2. **派费高的网点反而剩得少。** B 的派费比 A 高一毛多，一票却只剩三分：操作交给中心、全部直营业务员，投递成本高。进港赚不赚钱，看投递和操作怎么安排，不只看派费。
3. **直送比计件业务员便宜两毛多**，但按月付工资的货车直送线路，件少的时候短驳一票能到七毛五。直送线路也要按单位时间核算。
4. **固定工资的业务员，件量一掉单票成本就涨。** 成本单上的差异原因原话就是「固定工资人员件量下降」。

## 还缺什么

- 出港线还没有一手成本单（上门揽件、出港操作、支线运输），出港仍是示意数据。
- 两份单子月份不同，只比结构，不比好坏。
